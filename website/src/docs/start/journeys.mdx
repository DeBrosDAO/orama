# Choose your path

Pick the journey that matches what you want to do. Each one is a reading order, not a menu: follow it top to bottom.

## I want to build an app on a cluster

You already have a gateway URL (a cluster someone runs, or your own).

1. [Quickstart](/docs/developer/getting-started): install the CLI, add an environment, sign in, deploy.
2. [Namespaces](/docs/developer/namespaces): the unit you work inside.
3. [Sign-in and sessions](/docs/developer/sign-in) and [API keys and access control](/docs/developer/access-control): who your users are and what each key may do.
4. The services you need: [deployments](/docs/developer/deployments), [databases](/docs/developer/databases), [cache](/docs/developer/cache), [storage](/docs/developer/storage), [pub/sub](/docs/developer/pubsub), [functions](/docs/developer/functions), [push](/docs/developer/push), [WebRTC](/docs/developer/webrtc), [vault](/docs/developer/vault), [domains](/docs/developer/domains).
5. Reference: [TypeScript SDK](/docs/developer/sdk-reference), [CLI](/docs/developer/cli-overview), [gateway HTTP API](/docs/developer/api-surface).

## I want to run a cluster from nothing

You have a few VPSes and a domain. You want a working cluster and no help from anyone.

1. [What you need](/docs/operator/getting-started): machines, domain, your own computer.
2. [Install a cluster from scratch](/docs/operator/install-from-scratch): the whole sequence, with a check after every step.
3. [DNS and nameservers](/docs/operator/nameserver) and [TLS and certificates](/docs/operator/tls-certificates).
4. [Create your first namespace and deploy](/docs/operator/first-app).
5. Day two: [monitoring](/docs/operator/monitoring), [upgrades](/docs/operator/upgrades), [backups](/docs/developer/backups), [troubleshooting](/docs/operator/troubleshooting).

Just want to try it on one machine? Read [One-VPS evaluation](/docs/operator/one-vps) instead. It is not highly available.

## I want to create a network

You have fresh machines and want a chain of your own, with those machines as its first validators.

1. [What you need](/docs/operator/getting-started): machines, host keys, RootWallet.
2. [Create a network](/docs/operator/setup#create-a-network): `orama setup --create-network`, what it builds and in what order.
3. [Validators and staking](/docs/blockchain/validators): the bootstrap committee it creates, and how its power hands over to staked validators.
4. [Publish it](/docs/operator/setup#publish-it): the DNS records, the registry and the website copy that let others join.
